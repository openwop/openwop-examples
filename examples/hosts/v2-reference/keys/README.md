# Bundle-signing key

`host.pub.pem` is the Ed25519 public key (SPKI PEM) that verifies `../bundle-v3.json` (`signature.keyId: v2-reference-1`, conformance.md §Bundle v3). The private half, `host.pem` (PKCS8 PEM), is generated by `npm run keygen` and is gitignored — it never enters the repository. Rotate with `node scripts/keygen.mjs --force` and re-sign under a new key id.
