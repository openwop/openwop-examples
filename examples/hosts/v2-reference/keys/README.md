# Bundle-signing key

`host.pub.pem` is the Ed25519 public key (SPKI PEM) that verifies `../bundle-v3.json` (`signature.keyId: v2-reference-4` since the 2026-09-20 rotation (`v2-reference-3` verified the 2.3.1–2.25.0 bundles and `v2-reference-2` the 2.1.6 bundle; their public halves are in git history); `v2-reference-1` verified the rc.16 bundle and its public half is in git history; conformance.md §Bundle v3). The private half, `host.pem` (PKCS8 PEM), is generated by `npm run keygen` and is gitignored — it never enters the repository. Rotate with `node scripts/keygen.mjs --force` and re-sign under a new key id.
